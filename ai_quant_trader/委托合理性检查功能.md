# 委托合理性检查功能

**创建时间**: 2026-03-13 07:40  
**功能**: 自动检查并清理不合理委托  
**目标**: 确保委托始终保持在合理状态

---

## 功能概述

### 核心功能

1. **从交易所拉取现有委托**
2. **检查委托合理性**
3. **自动取消不合理委托**

### 不合理定义

| 类型 | 定义 | 默认阈值 | 处理方式 |
|------|------|---------|---------|
| **数量太多** | 委托数量超过限制 | > 4 个 | 取消最早的委托 |
| **间隔太近** | 价格间距过小 | < 10 USDT | 取消价格较低的委托 |
| **时间太久** | 挂单时间过长 | > 60 分钟 | 取消超时委托 |

---

## 工作原理

### 检查流程

```
每个交易周期开始：
  
1. 从交易所拉取现有委托
   └─ 调用 API 获取未成交订单

2. 检查委托合理性
   ├─ 数量检查：是否超过 4 个
   ├─ 间距检查：是否有 < 10 USDT
   └─ 时间检查：是否超过 60 分钟

3. 取消不合理委托
   ├─ 合并所有不合理委托
   ├─ 去重
   └─ 批量取消

4. 记录清理日志
   └─ 清理原因和数量
```

### 检查时机

**时机**: 每个交易周期开始时（优先执行）

**频率**: 约每 5-10 秒一次

**优先级**: 最高（在市场数据分析之前）

## 清理规则详解

### 1. 数量太多

**规则**: 委托数量 > 最大限制

**处理**: 按时间排序，取消最早的委托

**示例**:
```
当前委托:
  1. 70,419.40 - 0.002 BTC (07:30:30)
  2. 70,401.00 - 0.005 BTC (07:32:47)
  3. 70,401.00 - 0.002 BTC (07:32:47)
  4. 70,389.90 - 0.002 BTC (07:32:42)
  5. 70,350.00 - 0.002 BTC (07:33:00) ❌ 第 5 个

检查:
  数量 = 5 > 4 ❌
  
结果:
  ✅ 取消订单 1 (最早的)
```

### 2. 间隔太近

**规则**: 价格间距 < 最小间距

**处理**: 按价格排序，取消价格较低的委托

**示例**:
```
当前委托:
  1. 70,419.40 - 0.002 BTC
  2. 70,401.00 - 0.005 BTC
  3. 70,389.90 - 0.002 BTC

检查:
  70,401.00 - 70,389.90 = 11.10 USDT < 10 USDT ❌
  
结果:
  ✅ 取消订单 3 (价格较低)
  ✅ 保留订单 2 (价格较高，更接近成交)
```

### 3. 时间太久

**规则**: 挂单时间 > 超时时间

**处理**: 直接取消超时委托

**示例**:
```
当前委托:
  1. 70,419.40 - 0.002 BTC (06:30:00) ❌ 70 分钟前
  2. 70,401.00 - 0.005 BTC (07:30:00)
  3. 70,389.90 - 0.002 BTC (07:32:00)

检查:
  订单 1: 70 分钟 > 60 分钟 ❌
  
结果:
  ✅ 取消订单 1
```
