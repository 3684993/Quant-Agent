# 暴露量限制功能实现

## 问题描述

用户要求：持仓最大数量 0.02 BTC。
- 如果没有持仓，那可委托的数量就是 0.02
- 如果已经有持仓数量 0.01，那可委托的数量就剩下 0.01

同时需要：
- 允许间隔一定范围的分批委托
- 但委托的总数量不能超过 0.02 BTC

## 核心逻辑

**暴露量计算公式**：
```
总暴露量 = 当前持仓 + 现有未成交委托 + 新委托
可用额度 = 最大持仓限制 - 当前持仓 - 现有未成交委托
```

**委托规则**：
- 只有当 `总暴露量 <= 最大持仓限制` 时，才允许委托
- 允许分批委托（多个不同价格的订单）
- 所有未成交委托的总数量 + 当前持仓不能超过限制

### 1. 新增 `check_exposure_limit` 函数

**位置**: `order_executor.py` 第 1110-1163 行

**功能**: 检查暴露量限制

```python
def check_exposure_limit(self, symbol: str, side: str, new_size: float) -> Dict:
    """
    检查暴露量限制：持仓 + 未成交委托 + 新委托 <= 0.02 BTC
    
    返回:
    - allowed: 是否允许委托
    - available_size: 还可委托的数量
    - reason: 原因说明
    """
```

**检查流程**:
1. 获取当前持仓数量
2. 获取现有未成交委托总数量
3. 计算总暴露量 = 持仓 + 委托 + 新委托
4. 计算可用额度 = 0.02 - 持仓 - 委托
5. 如果总暴露量 > 0.02，拒绝委托

## 与分批委托的配合

系统现在支持：
1. **分批建仓**: 可以创建多个不同价格的建仓委托
2. **总数量限制**: 所有委托的总数量 + 当前持仓 <= 0.02 BTC
3. **智能检查**: 自动计算可用额度，防止超限

**示例**:
- 当前持仓：0 BTC
- 可创建委托：
  - 委托 1: 0.005 BTC @ 70000
  - 委托 2: 0.005 BTC @ 70100
  - 委托 3: 0.005 BTC @ 70200
  - 委托 4: 0.005 BTC @ 70300
  - **总计**: 0.02 BTC ✅

- 如果再尝试创建委托 5: 0.001 BTC @ 70400
  - 总暴露量 = 0.02 + 0.001 = 0.021 > 0.02
  - **结果**: ❌ 被拒绝

## 错误修复

### 问题：`'BinanceClient' object has no attribute 'position_manager'`

**错误日志**:
```
ERROR:ai_quant_trader:检查暴露量失败：'BinanceClient' object has no attribute 'position_manager'
```

**原因**: 
- `check_exposure_limit` 函数中使用了错误的调用方式：`self.client.position_manager.get_position(symbol)`
- 但 `BinanceClient` 类没有 `position_manager` 属性

**修复方法**:
- 改用正确的调用方式：`self.client.get_position(symbol)`
- `BinanceClient` 类已经有 `get_position` 方法（第 158-179 行）
- 使用 `position_amt` 字段获取持仓量（做多时为正，做空时为负）

**修复后的代码**:
```python
# 获取当前持仓
position = self.client.get_position(symbol)
# 使用 position_amt 获取持仓量（做多时为正，做空时为负）
current_position = abs(position.get('position_amt', 0)) if position else 0
```
