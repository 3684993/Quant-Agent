## 🔴 未修复的核心问题

### 问题 1: **重复委托检查逻辑错误** 🔴🔴🔴

**严重程度**: 🔴 致命 - 导致系统无法建仓

**现象**:
```
18:11:27 | 发现重复委托：价格=69610.00 vs 69866.70, 数量=0.0050 vs 0.0050
18:11:27 | 发现重复委托，跳过执行：long 0.005 BTCUSDT @ 69866.7
18:11:27 | ORDER_REPLACE: BTCUSDT old=12764871695 reason=timeout new_price=69866.70 success=False

18:19:39 | 发现重复委托：价格=69866.70 vs 69829.20, 数量=0.0200 vs 0.0200
18:19:39 | 发现重复委托，跳过执行：long 0.02 BTCUSDT @ 69829.2
18:19:39 | ORDER_REPLACE: BTCUSDT old=12765522665 reason=timeout new_price=69829.20 success=False

18:22:02 | 发现重复委托：价格=69866.70 vs 69911.80, 数量=0.0200 vs 0.0200
18:22:02 | 发现重复委托，跳过执行：long 0.02 BTCUSDT @ 69911.8
18:22:02 | ORDER_REPLACE: BTCUSDT old=12765522665 reason=timeout new_price=69911.80 success=False
```

**分析**:
1. **价格不同**：旧订单价格 69866.70，新订单价格 69829.20 / 69911.80
2. **数量相同**：都是 0.0200
3. **方向相同**：都是 long
4. **被阻止**：系统认为是"重复委托"，跳过执行

**根因**:
- "重复委托"检查逻辑只比较 side 和 size
- **没有比较 price 或者 price 比较逻辑错误**
- 导致价格不同的订单也被认为是"重复"

**推测错误代码**:
```python
def is_duplicate(self, new_order, existing_orders):
    for order in existing_orders:
        # ❌ 错误：只检查 side 和 size，不检查 price
        if (order.get("side") == new_order["side"] and
            abs(order.get("size") - new_order["size"]) < 0.0001):
            return True
    return False
```

**正确代码应该是**:
```python
def is_duplicate(self, new_order, existing_orders):
    for order in existing_orders:
        # ✅ 正确：同时检查 side, size 和 price
        if (order.get("side") == new_order["side"] and
            abs(order.get("size") - new_order["size"]) < 0.0001 and
            abs(order.get("price") - new_order["price"]) < 1.0):  # 允许 1 美元误差
            return True
    return False
```

**或者**（更合理的逻辑）:
```python
def is_duplicate(self, new_order, existing_orders):
    for order in existing_orders:
        # ✅ 只阻止完全相同的订单
        # 如果价格不同，说明是调整后的新订单，应该允许
        if (order.get("symbol") == new_order["symbol"] and
            order.get("side") == new_order["side"] and
            abs(order.get("size") - new_order["size"]) < 0.0001 and
            abs(order.get("price") - new_order["price"]) < 1.0):
            return True
    return False
```
