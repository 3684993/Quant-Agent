## 补仓策略

### 补仓条件

1. **趋势未变**: 当前趋势与持仓方向一致
2. **置信度高**: AI 置信度 > 0.7
3. **价格优势**: 补仓价格优于开仓价格
4. **仓位控制**: 补仓后总仓位不超过限制

### 补仓价格计算

```python
def _create_add_position_order(...):
    # 补仓价格（在当前价下方补仓）
    if side == "long":
        add_price = current_price * 0.995  # 低于当前价 0.5%
    else:  # short
        add_price = current_price * 1.005  # 高于当前价 0.5%
    
    # 补仓尺寸（原仓位的一半）
    add_size = position_size * 0.5
    
    # 创建补仓委托
    result = self.order_executor.open_position(
        symbol=symbol,
        side="BUY" if side == "long" else "SELL",
        size=add_size,
        order_type="limit",
        price=add_price,
        reduce_only=False
    )
```

## 风险提示

### 补仓风险

⚠️ **补仓可能放大亏损**
- 补仓后如果趋势反转，亏损会加倍
- 需要严格设置止损

⚠️ **补仓可能错过更好价格**
- 补仓价格设置不合理可能导致过早补仓
- 应该基于技术指标（如布林线）设置补仓价

⚠️ **补仓可能超过仓位限制**
- 补仓后总仓位不能超过最大限制
- 需要检查暴露量限制
