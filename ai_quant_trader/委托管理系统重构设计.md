**版本**: 1.0

---

## 一、现状分析

### 1.1 当前问题

通过这段时间的实战，我们发现当前委托管理存在以下问题：

#### 架构层面
1. **职责不清**: `OrderManager`、`OrderExecutor`、`OrderRationalityChecker` 职责重叠
2. **检查分散**: 重复检查、间距检查、暴露量检查分散在不同地方
3. **缺乏状态机**: 委托状态管理混乱，没有清晰的状态流转
4. **错误处理不统一**: 各处错误处理方式不一致

#### 功能层面
1. **重复委托漏检**: 价格相同但数量不同的委托绕过检查
2. **清理不及时**: 不合理委托不能及时清理
3. **配置不灵活**: 硬编码参数多，配置化管理不足
4. **监控不完善**: 缺少委托全生命周期监控

#### 性能层面
1. **频繁 API 调用**: 每次检查都调用交易所 API
2. **缺乏缓存**: 订单数据没有缓存机制
3. **同步阻塞**: 检查逻辑阻塞主线程

---

## 二、设计原则

### 2.1 核心原则

1. **单一职责**: 每个类只负责一个职责
2. **开闭原则**: 对扩展开放，对修改关闭
3. **依赖倒置**: 依赖抽象接口，不依赖具体实现
4. **接口隔离**: 使用细粒度接口，避免胖接口

### 2.2 交易特定原则

1. **安全第一**: 任何操作都不能危及资金安全
2. **故障安全**: 系统故障时自动进入安全状态
3. **幂等性**: 同一操作多次执行结果一致
4. **可追溯**: 所有操作都有完整日志和审计

### 3.2 模块划分

#### 核心模块

1. **Order Builder** - 委托构建器
   - 负责创建、修改委托订单
   - 处理价格、数量的格式化
   - 生成客户端订单 ID

2. **Order Validator** - 委托验证器
   - 验证委托的合法性
   - 执行所有检查（重复、间距、暴露量等）
   - 返回验证结果和错误信息

3. **Order Executor** - 委托执行器
   - 执行委托的提交、取消、查询
   - 处理交易所 API 调用
   - 管理订单状态

4. **Order Manager** - 委托管理器（协调器）
   - 协调各个组件
   - 管理委托生命周期
   - 提供统一的外部接口

#### 辅助模块

5. **Risk Checker** - 风险检查器
   - 暴露量检查
   - 仓位限制检查
   - 资金充足性检查

6. **Rationality Checker** - 合理性检查器
   - 委托数量检查
   - 价格间距检查
   - 时间超时检查

7. **State Machine** - 状态机
   - 管理委托状态流转
   - 状态变更通知
   - 状态持久化

8. **Order Repository** - 委托仓库
   - 订单数据缓存
   - 订单数据持久化
   - 订单历史查询

9. **Event Bus** - 事件总线
   - 异步事件通知
   - 解耦组件通信
   - 事件订阅/发布

```python
from typing import Optional
from decimal import Decimal
import uuid

class OrderBuilder:
    """委托构建器"""
    
    def __init__(self, symbol: str, precision_service: 'PrecisionService'):
        self.symbol = symbol
        self.precision_service = precision_service
        self._side: Optional[OrderSide] = None
        self._type: Optional[OrderType] = None
        self._quantity: float = 0.0
        self._price: Optional[float] = None
        self._reduce_only: bool = False
        self._client_order_id: str = ""
    
    def side(self, side: str) -> 'OrderBuilder':
        """设置方向"""
        self._side = OrderSide(side.upper())
        return self
    
    def type(self, type: str) -> 'OrderBuilder':
        """设置类型"""
        self._type = OrderType(type.upper())
        return self
    
    def quantity(self, quantity: float) -> 'OrderBuilder':
        """设置数量（自动格式化）"""
        self._quantity = self.precision_service.round_quantity(
            self.symbol, quantity
        )
        return self
    
    def price(self, price: float) -> 'OrderBuilder':
        """设置价格（自动格式化）"""
        if self._type in [OrderType.LIMIT, OrderType.STOP_LIMIT]:
            self._price = self.precision_service.round_price(
                self.symbol, price
            )
        return self
    
    def reduce_only(self, reduce_only: bool) -> 'OrderBuilder':
        """设置仅减仓"""
        self._reduce_only = reduce_only
        return self
    
    def client_order_id(self, client_order_id: str) -> 'OrderBuilder':
        """设置客户端订单 ID"""
        self._client_order_id = client_order_id
        return self
    
    def build(self) -> Order:
        """构建订单"""
        # 验证必填字段
        if not self._side:
            raise ValueError("Order side is required")
        if not self._type:
            raise ValueError("Order type is required")
        if self._quantity <= 0:
            raise ValueError("Order quantity must be positive")
        
        # 生成客户端订单 ID
        if not self._client_order_id:
            self._client_order_id = self._generate_client_order_id()
        
        # 创建订单
        return Order(
            order_id="",  # 由交易所返回
            symbol=self.symbol,
            side=self._side,
            type=self._type,
            quantity=self._quantity,
            price=self._price,
            reduce_only=self._reduce_only,
            client_order_id=self._client_order_id,
        )
    
    def _generate_client_order_id(self) -> str:
        """生成客户端订单 ID"""
        # 格式：{prefix}_{timestamp}_{uuid}
        prefix = "om"  # order management
        timestamp = datetime.now().strftime("%Y%m%d%H%M%S")
        unique_id = str(uuid.uuid4())[:8]
        return f"{prefix}_{timestamp}_{unique_id}"
```

```python
from typing import List, Tuple
from dataclasses import dataclass

@dataclass
class ValidationResult:
    """验证结果"""
    is_valid: bool
    errors: List[str]
    warnings: List[str]
    
    @classmethod
    def ok(cls) -> 'ValidationResult':
        return cls(is_valid=True, errors=[], warnings=[])
    
    @classmethod
    def fail(cls, errors: List[str], warnings: List[str] = None) -> 'ValidationResult':
        return cls(is_valid=False, errors=errors, warnings=warnings or [])

class OrderValidator:
    """委托验证器"""
    
    def __init__(
        self,
        risk_checker: 'RiskChecker',
        rationality_checker: 'RationalityChecker',
        order_repository: 'OrderRepository',
    ):
        self.risk_checker = risk_checker
        self.rationality_checker = rationality_checker
        self.order_repository = order_repository
    
    def validate(self, order: Order) -> ValidationResult:
        """验证订单"""
        errors = []
        warnings = []
        
        # 1. 基础验证
        base_result = self._validate_basic(order)
        errors.extend(base_result.errors)
        warnings.extend(base_result.warnings)
        
        # 2. 风险检查
        risk_result = self.risk_checker.check(order)
        if not risk_result.is_valid:
            errors.extend(risk_result.errors)
        
        # 3. 合理性检查
        rationality_result = self.rationality_checker.check(
            order, 
            self.order_repository.get_active_orders(order.symbol)
        )
        if not rationality_result.is_valid:
            errors.extend(rationality_result.errors)
        
        # 4. 重复检查
        duplicate_result = self._check_duplicate(order)
        if duplicate_result:
            errors.append("Duplicate order detected")
        
        return ValidationResult(
            is_valid=len(errors) == 0,
            errors=errors,
            warnings=warnings,
        )
    
    def _validate_basic(self, order: Order) -> ValidationResult:
        """基础验证"""
        errors = []
        warnings = []
        
        # 检查数量
        if order.quantity <= 0:
            errors.append("Quantity must be positive")
        
        # 检查价格（限价单）
        if order.type in [OrderType.LIMIT, OrderType.STOP_LIMIT]:
            if not order.price or order.price <= 0:
                errors.append("Price is required for limit order")
        
        # 检查 reduce_only
        if order.reduce_only and order.side == OrderSide.BUY:
            warnings.append("ReduceOnly buy order may be rejected")
        
        return ValidationResult(
            is_valid=len(errors) == 0,
            errors=errors,
            warnings=warnings,
        )
    
    def _check_duplicate(self, order: Order) -> bool:
        """检查重复订单"""
        active_orders = self.order_repository.get_active_orders(order.symbol)
        
        for existing in active_orders:
            # 价格相同即认为是重复（不管数量）
            if existing.price and order.price:
                if abs(existing.price - order.price) < 0.5:  # 0.5 USDT tolerance
                    return True
        
        return False
```

```python
from typing import Dict

class RiskChecker:
    """风险检查器"""
    
    def __init__(self, config: 'RiskConfig'):
        self.config = config
    
    def check(self, order: Order) -> ValidationResult:
        """风险检查"""
        errors = []
        
        # 1. 暴露量检查（仅开仓委托）
        if not order.reduce_only:
            exposure_result = self._check_exposure(order)
            if not exposure_result.is_valid:
                errors.extend(exposure_result.errors)
        
        # 2. 仓位限制检查
        position_result = self._check_position_limit(order)
        if not position_result.is_valid:
            errors.extend(position_result.errors)
        
        # 3. 资金充足性检查
        capital_result = self._check_capital(order)
        if not capital_result.is_valid:
            errors.extend(capital_result.errors)
        
        return ValidationResult(
            is_valid=len(errors) == 0,
            errors=errors,
            warnings=[],
        )
    
    def _check_exposure(self, order: Order) -> ValidationResult:
        """暴露量检查"""
        # 获取当前暴露量
        current_exposure = self._get_current_exposure(order.symbol)
        new_exposure = current_exposure + order.quantity
        
        if new_exposure > self.config.max_exposure:
            return ValidationResult.fail([
                f"Exposure limit exceeded: {new_exposure:.4f} > {self.config.max_exposure:.4f}"
            ])
        
        return ValidationResult.ok()
    
    def _check_position_limit(self, order: Order) -> ValidationResult:
        """仓位限制检查"""
        # 获取当前仓位
        current_position = self._get_position(order.symbol)
        
        # 计算新仓位
        if order.side == OrderSide.BUY:
            new_position = current_position + order.quantity
        else:
            new_position = current_position - order.quantity
        
        if abs(new_position) > self.config.max_position_size:
            return ValidationResult.fail([
                f"Position limit exceeded: {abs(new_position):.4f} > {self.config.max_position_size:.4f}"
            ])
        
        return ValidationResult.ok()
    
    def _check_capital(self, order: Order) -> ValidationResult:
        """资金充足性检查"""
        required_capital = self._calculate_required_capital(order)
        available_capital = self._get_available_capital()
        
        if required_capital > available_capital:
            return ValidationResult.fail([
                f"Insufficient capital: {required_capital:.2f} > {available_capital:.2f}"
            ])
        
        return ValidationResult.ok()
```

```python
from datetime import timedelta

class RationalityChecker:
    """合理性检查器"""
    
    def __init__(self, config: 'RationalityConfig'):
        self.config = config
    
    def check(self, order: Order, active_orders: List[Order]) -> ValidationResult:
        """合理性检查"""
        errors = []
        
        # 1. 数量检查
        quantity_result = self._check_quantity(order, active_orders)
        if not quantity_result.is_valid:
            errors.extend(quantity_result.errors)
        
        # 2. 间距检查
        spacing_result = self._check_spacing(order, active_orders)
        if not spacing_result.is_valid:
            errors.extend(spacing_result.errors)
        
        # 3. 超时检查（针对已有订单）
        timeout_result = self._check_timeout(active_orders)
        if not timeout_result.is_valid:
            errors.extend(timeout_result.errors)
        
        return ValidationResult(
            is_valid=len(errors) == 0,
            errors=errors,
            warnings=[],
        )
    
    def _check_quantity(self, order: Order, active_orders: List[Order]) -> ValidationResult:
        """数量检查"""
        same_side_count = sum(
            1 for o in active_orders 
            if o.side == order.side and o.symbol == order.symbol
        )
        
        if same_side_count >= self.config.max_orders_per_side:
            return ValidationResult.fail([
                f"Too many {order.side.value} orders: {same_side_count} >= {self.config.max_orders_per_side}"
            ])
        
        return ValidationResult.ok()
    
    def _check_spacing(self, order: Order, active_orders: List[Order]) -> ValidationResult:
        """间距检查"""
        if not order.price:
            return ValidationResult.ok()
        
        same_side_orders = [
            o for o in active_orders 
            if o.side == order.side and o.symbol == order.symbol and o.price
        ]
        
        for existing in same_side_orders:
            spacing = abs(existing.price - order.price)
            if spacing < self.config.min_price_spacing:
                return ValidationResult.fail([
                    f"Price spacing too small: {spacing:.2f} < {self.config.min_price_spacing:.2f}"
                ])
        
        return ValidationResult.ok()
    
    def _check_timeout(self, active_orders: List[Order]) -> ValidationResult:
        """超时检查"""
        now = datetime.now()
        timeout_orders = []
        
        for order in active_orders:
            elapsed = now - order.created_at
            if elapsed > self.config.order_timeout:
                timeout_orders.append(order.order_id)
        
        if timeout_orders:
            return ValidationResult.fail([
                f"Orders timeout: {len(timeout_orders)} orders older than {self.config.order_timeout}"
            ])
        
        return ValidationResult.ok()
```

#### Order Manager (Coordinator)

```python
from typing import Optional, List
from enum import Enum

class OrderAction(Enum):
    SUBMIT = "SUBMIT"
    CANCEL = "CANCEL"
    MODIFY = "MODIFY"

class OrderManager:
    """委托管理器（协调器）"""
    
    def __init__(
        self,
        builder: OrderBuilder,
        validator: OrderValidator,
        executor: OrderExecutor,
        repository: OrderRepository,
        event_bus: EventBus,
    ):
        self.builder = builder
        self.validator = validator
        self.executor = executor
        self.repository = repository
        self.event_bus = event_bus
    
    def submit_order(
        self,
        symbol: str,
        side: str,
        type: str,
        quantity: float,
        price: Optional[float] = None,
        reduce_only: bool = False,
    ) -> Tuple[bool, Optional[str]]:
        """
        提交订单
        
        Returns:
            (success, error_message)
        """
        try:
            # 1. 构建订单
            order = (
                self.builder(symbol)
                .side(side)
                .type(type)
                .quantity(quantity)
                .price(price)
                .reduce_only(reduce_only)
                .build()
            )
            
            # 2. 验证订单
            validation_result = self.validator.validate(order)
            if not validation_result.is_valid:
                error_msg = "; ".join(validation_result.errors)
                logger.warning(f"Order validation failed: {error_msg}")
                return False, error_msg
            
            # 3. 提交订单
            submit_result = self.executor.submit(order)
            if not submit_result.success:
                return False, submit_result.error
            
            # 4. 保存到仓库
            order.order_id = submit_result.order_id
            self.repository.save(order)
            
            # 5. 发布事件
            self.event_bus.publish(OrderSubmittedEvent(order))
            
            logger.info(f"Order submitted: {order.order_id}")
            return True, None
            
        except Exception as e:
            logger.error(f"Submit order failed: {e}")
            return False, str(e)
    
    def cancel_order(self, symbol: str, order_id: str) -> bool:
        """取消订单"""
        try:
            result = self.executor.cancel(symbol, order_id)
            if result.success:
                # 更新仓库
                self.repository.update_status(order_id, OrderStatus.CANCELED)
                # 发布事件
                self.event_bus.publish(OrderCanceledEvent(order_id))
                logger.info(f"Order canceled: {order_id}")
                return True
            else:
                logger.warning(f"Cancel order failed: {result.error}")
                return False
        except Exception as e:
            logger.error(f"Cancel order failed: {e}")
            return False
    
    def cleanup_unreasonable_orders(self, symbol: str) -> int:
        """清理不合理订单"""
        try:
            # 获取活跃订单
            active_orders = self.repository.get_active_orders(symbol)
            
            # 合理性检查
            validation_result = self.validator.validate_orders(active_orders)
            
            # 取消不合理订单
            cancelled_count = 0
            for order_id in validation_result.unreasonable_order_ids:
                if self.cancel_order(symbol, order_id):
                    cancelled_count += 1
            
            if cancelled_count > 0:
                logger.info(f"Cleaned up {cancelled_count} unreasonable orders")
            
            return cancelled_count
            
        except Exception as e:
            logger.error(f"Cleanup failed: {e}")
            return 0
    
    def get_order_status(self, order_id: str) -> Optional[Order]:
        """获取订单状态"""
        return self.repository.get(order_id)
    
    def get_active_orders(self, symbol: str) -> List[Order]:
        """获取活跃订单"""
        return self.repository.get_active_orders(symbol)
```

### 4.3 事件系统

```python
from abc import ABC, abstractmethod
from typing import List, Callable

class Event(ABC):
    """事件基类"""
    @abstractmethod
    def get_type(self) -> str:
        pass

class OrderSubmittedEvent(Event):
    def __init__(self, order: Order):
        self.order = order
    
    def get_type(self) -> str:
        return "ORDER_SUBMITTED"

class OrderCanceledEvent(Event):
    def __init__(self, order_id: str):
        self.order_id = order_id
    
    def get_type(self) -> str:
        return "ORDER_CANCELED"

class OrderFilledEvent(Event):
    def __init__(self, order: Order, fill_price: float, fill_quantity: float):
        self.order = order
        self.fill_price = fill_price
        self.fill_quantity = fill_quantity
    
    def get_type(self) -> str:
        return "ORDER_FILLED"

class EventBus:
    """事件总线"""
    
    def __init__(self):
        self._subscribers: Dict[str, List[Callable]] = {}
    
    def subscribe(self, event_type: str, handler: Callable):
        """订阅事件"""
        if event_type not in self._subscribers:
            self._subscribers[event_type] = []
        self._subscribers[event_type].append(handler)
    
    def publish(self, event: Event):
        """发布事件"""
        event_type = event.get_type()
        if event_type in self._subscribers:
            for handler in self._subscribers[event_type]:
                try:
                    handler(event)
                except Exception as e:
                    logger.error(f"Event handler failed: {e}")
```

### 4.4 仓储模式

```python
from typing import Dict, List, Optional
from datetime import datetime

class OrderRepository:
    """订单仓库"""
    
    def __init__(self, cache_service: 'CacheService', db_service: 'DBService'):
        self.cache = cache_service
        self.db = db_service
    
    def save(self, order: Order):
        """保存订单"""
        # 保存到缓存
        self.cache.set(f"order:{order.order_id}", order, ttl=3600)
        # 保存到数据库
        self.db.insert("orders", order.to_dict())
    
    def get(self, order_id: str) -> Optional[Order]:
        """获取订单"""
        # 先查缓存
        order = self.cache.get(f"order:{order_id}")
        if order:
            return order
        
        # 再查数据库
        data = self.db.query_one("orders", {"order_id": order_id})
        if data:
            order = self._dict_to_order(data)
            self.cache.set(f"order:{order_id}", order, ttl=3600)
            return order
        
        return None
    
    def get_active_orders(self, symbol: str) -> List[Order]:
        """获取活跃订单"""
        # 从缓存获取
        all_orders = self.cache.get_by_pattern(f"order:*")
        
        active_orders = [
            order for order in all_orders
            if order.symbol == symbol and order.is_active
        ]
        
        return active_orders
    
    def update_status(self, order_id: str, status: OrderStatus):
        """更新订单状态"""
        order = self.get(order_id)
        if order:
            order.status = status
            order.updated_at = datetime.now()
            self.save(order)
    
    def _dict_to_order(self, data: Dict) -> Order:
        """字典转 Order 对象"""
        return Order(
            order_id=data['order_id'],
            symbol=data['symbol'],
            side=OrderSide(data['side']),
            type=OrderType(data['type']),
            quantity=data['quantity'],
            price=data.get('price'),
            status=OrderStatus(data['status']),
            filled_quantity=data.get('filled_quantity', 0),
            avg_price=data.get('avg_price', 0),
            reduce_only=data.get('reduce_only', False),
            client_order_id=data.get('client_order_id', ''),
            created_at=datetime.fromisoformat(data['created_at']),
            updated_at=datetime.fromisoformat(data['updated_at']),
        )
```
