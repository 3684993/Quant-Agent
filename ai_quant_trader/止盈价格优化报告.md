# 止盈价格优化报告

**优化时间**: 2026-03-13 00:01  
**问题**: 止盈价格设置完全不对，和开仓价太近  
**解决方案**: 使用 1 分钟布林线边缘设置止盈价格

---

## 问题描述

### 错误日志
```
2026-03-13 00:01:46 | ERROR | Open position error: (400, -2022, 'ReduceOnly Order is rejected.')
WARNING: [ORDER] 止盈委托提交失败
```

### 问题分析

1. **止盈价格过近**: 止盈价格距离开仓价太近，没有设置在合理的技术位置
2. **固定百分比错误**: 使用固定的 2% 百分比，没有考虑市场技术面
3. **缺少布林线参考**: 没有参考 1 分钟布林线边缘设置止盈

---

## 优化方案

### 核心原则

✅ **止盈必须设置在 1 分钟布林线边缘**  
✅ **止盈不能靠近开仓价**  
✅ **最小距离要求**: 开仓价的 0.5% 以上

---

### 新的止盈计算逻辑

#### 多头持仓 (LONG)

```python
# 1. 获取 1 分钟布林线上轨
bb_upper_1m = get_bollinger_bands(symbol, "1m")["upper"]

# 2. 止盈设置在上轨下方 0.5% 处
take_profit_price = bb_upper_1m * 0.995

# 3. 确保止盈高于开仓价至少 0.5%
min_tp = entry_price * 1.005
take_profit_price = max(take_profit_price, min_tp)

# 示例:
# 开仓价：70,000 USDT
# 布林线上轨：71,000 USDT
# 止盈价：71,000 * 0.995 = 70,645 USDT (上轨边缘)
# 验证：70,645 > 70,000 * 1.005 = 70,350 ✅
```

#### 空头持仓 (SHORT)

```python
# 1. 获取 1 分钟布林线下轨
bb_lower_1m = get_bollinger_bands(symbol, "1m")["lower"]

# 2. 止盈设置在下轨上方 0.5% 处
take_profit_price = bb_lower_1m * 1.005

# 3. 确保止盈低于开仓价至少 0.5%
max_tp = entry_price * 0.995
take_profit_price = min(take_profit_price, max_tp)

# 示例:
# 开仓价：70,000 USDT
# 布林线下轨：69,000 USDT
# 止盈价：69,000 * 1.005 = 69,345 USDT (下轨边缘)
# 验证：69,345 < 70,000 * 0.995 = 69,650 ✅
```

### 新增辅助方法

**位置**: `scheduler.py` 第 1845-1888 行

```python
def _get_bollinger_bands(self, symbol: str, timeframe: str = "1m") -> Dict:
    """
    获取指定时间周期的布林线数据
    
    Args:
        symbol: 交易对
        timeframe: 时间周期（默认 1m）
        
    Returns:
        布林线数据字典：{upper, middle, lower}
    """
    try:
        # 从 market_data 获取布林线数据
        if hasattr(self, 'market_data') and self.market_data:
            if hasattr(self.market_data, 'get_indicators'):
                indicators = self.market_data.get_indicators(symbol, timeframe)
                if indicators and 'bollinger' in indicators:
                    bb = indicators['bollinger']
                    return {
                        "upper": float(bb.get("upper", 0)),
                        "middle": float(bb.get("middle", 0)),
                        "lower": float(bb.get("lower", 0))
                    }
        
        # 备用方案：从 indicators 参数获取
        if hasattr(self, '_last_indicators') and self._last_indicators:
            indicators = self._last_indicators.get(symbol, {})
            if 'bollinger' in indicators:
                bb = indicators['bollinger']
                return {
                    "upper": float(bb.get("upper", 0)),
                    "middle": float(bb.get("middle", 0)),
                    "lower": float(bb.get("lower", 0))
                }
        
        # 返回空数据
        logger.warning(f"无法获取{timeframe}布林线数据：{symbol}")
        return {"upper": 0, "middle": 0, "lower": 0}
        
    except Exception as e:
        logger.error(f"获取布林线数据失败：{symbol} {timeframe} - {e}")
        return {"upper": 0, "middle": 0, "lower": 0}
```

### 3. 动态调整

- ✅ 根据市场波动自动调整
- ✅ 布林线扩张时止盈更远
- ✅ 布林线收缩时止盈更近
