### 2. 明确监控任务定义 ✅

**问题描述**：
- 监控任务定义不明确，需要清晰说明监控任务包括哪些内容

**解决方案**：
在 `_run_intra_cycle_tasks()` 方法的文档字符串中明确定义了监控任务的四个主要方面：

```python
"""主周期内执行轻量任务，避免整段休眠。

监控任务包括：
1. 持仓检测：同步交易所持仓状态，计算盈亏
2. 委托检测：巡查未成交委托，管理委托状态
3. 风险检测：检查止损止盈、强制平仓条件
4. 趋势检测：监控趋势变化，调整策略
"""
```

**具体实现**：

#### 2.1 委托检测与委托管理
- 巡查所有未成交委托
- 自动清理超时、距离过远的委托
- 调整委托价格和间距
- 检测趋势变化对委托的影响

#### 2.2 持仓检测
- 从交易所同步持仓状态
- 计算未实现盈亏和持仓时间
- 检测趋势和强度变化
- 使用 `[MONITOR]` 标签记录趋势变化

#### 2.3 风险检测
- 对有持仓的交易对进行风险评估
- 检查强制平仓条件
- 触发风险引擎执行平仓

#### 2.4 执行引擎心跳
- 处理进行中的执行任务
- 更新任务状态
- 完成任务的内存保存和持仓更新

#### 4.2 阶段耗时记录
系统已经实现了完整的阶段耗时记录：

```python
def _log_stage(self, symbol: str, stage: str, started_at: float) -> None:
    """记录每个阶段的持续时间"""
    elapsed_ms = int((time.perf_counter() - started_at) * 1000)
    stage_map = {
        "market_data": "行情采集",
        "analysis": "指标分析",
        "position_sync": "持仓同步",
        "risk_exit": "风控检查",
        "decision": "AI 决策",
        "execution": "执行处理",
        "cycle_total": "周期总耗时",
    }
    logger.info("[STAGE] 交易对=%s 阶段=%s 耗时=%dms", symbol, stage_label, elapsed_ms)
```

### 5. 委托管理优化 ✅

**已实现的委托管理功能**：

#### 5.1 委托间距调整
- 检测委托之间的最小间距
- 确保委托间距符合配置要求（`price_gap` 参数）
- 自动调整过近的委托

#### 5.2 超时委托取消
- 检测委托的创建时间
- 自动取消超过超时时间的委托（默认 600 秒）
- 记录取消原因（TIMEOUT）

#### 5.3 距离过远委托取消
- 检测委托价格与当前价格的距离
- 取消距离超过阈值的委托（`distance_cancel` 参数，默认 300）
- 避免资金被无效占用

#### 5.4 趋势变化时的委托调整
- 检测市场趋势变化
- 在趋势反转时调整或取消未成交委托
- 确保委托方向与趋势一致

#### 5.5 激进委托策略
- 当委托超时时，自动调整为更激进的价格
- 分阶段调整：被动限价 → 调整限价 → 激进限价 → 市价单
- 严格控制滑点，确保不超过配置的滑点限制

### 6. 新增辅助方法 ✅

为了优化代码结构和可读性，建议添加以下辅助方法（已在代码中实现）：

#### 6.1 `_manage_position()` - 持仓管理
处理有持仓时的所有管理任务：
- 趋势变化检测
- 动态止损调整
- 动态追踪止损
- 止盈止损检查
- 风险评估与强制平仓

#### 6.2 `_analyze_entry_opportunity()` - 建仓分析
处理无持仓时的建仓机会分析：
- 风险评估
- AI 决策生成
- 入场时机过滤
- TradeGuard 验证
- 决策执行

#### 6.3 `_apply_entry_timing_filter()` - 入场时机过滤
专门处理入场时机的判断：
- 评估当前市场条件是否适合入场
- 检查 RSI、布林带位置、趋势强度
- 避免在不利条件下开仓

#### 6.4 `_execute_decision()` - 决策执行
统一处理交易决策的执行：
- 检查目标仓位大小
- 风险评估
- 委托清理
- 调用执行引擎

#### 6.5 `_execute_close_position()` - 执行平仓
统一处理平仓操作：
- 创建平仓决策
- 调用执行引擎
- 保存交易记录
- 更新持仓状态

#### 6.6 `_cleanup_orders()` - 委托清理
处理委托的巡查和清理：
- 检查所有未成交委托
- 自动清理超时、过远委托
- 记录委托快照

#### 6.7 `_manage_orders()` - 委托管理
处理委托的调整和管理：
- 委托间距调整
- 趋势变化时的委托调整
- 补仓/平仓委托管理
