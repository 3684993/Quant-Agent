### 问题分析

#### 1. **重复委托检查逻辑错误** 🔴

**现象**:
- 旧订单价格：69610.00
- 新订单价格：69866.70 / 69845.90 / 69745.90 / 69645.90
- **价格不同**，但系统仍然认为是"重复委托"

**推测根因**:
```python
# 可能的错误代码逻辑
def check_duplicate_order(self, symbol, side, size, price):
    existing_orders = self.get_existing_orders(symbol)
    
    for order in existing_orders:
        # 错误：只检查 side 和 size，不检查 price
        if (order.get("side") == side and 
            abs(order.get("size") - size) < 0.0001):
            logger.warning(f"发现重复委托：价格={order.get('price')} vs {price}")
            return True
    
    return False
```

**正确逻辑应该是**:
```python
def check_duplicate_order(self, symbol, side, size, price):
    existing_orders = self.get_existing_orders(symbol)
    
    for order in existing_orders:
        # 正确：同时检查 side, size 和 price
        if (order.get("side") == side and 
            abs(order.get("size") - size) < 0.0001 and
            abs(order.get("price") - price) < 1.0):  # 允许微小价格差异
            logger.warning(f"发现重复委托")
            return True
    
    return False
```

或者：
```python
def check_duplicate_order(self, symbol, side, size, price):
    existing_orders = self.get_existing_orders(symbol)
    
    for order in existing_orders:
        # 或者：只检查完全相同的订单（包括价格）

            abs(order.get("price") - price) < 1.0):
```

## 🔴 核心问题总结

### 问题 1: 重复委托检查过于严格

**当前行为**:
- 只要 side 和 size 相同，就认为是重复委托
- **忽略了价格差异**
- 导致新价格的订单无法创建

**影响**:
- 🔴 订单无法调整价格
- 🔴 无法响应市场变化
- 🔴 系统陷入死循环

**修复建议**:
```python
# 修改重复委托检查逻辑
def is_duplicate_order(self, new_order, existing_orders):
    for order in existing_orders:
        # 只阻止完全相同的订单
        if (order.get("symbol") == new_order["symbol"] and
            order.get("side") == new_order["side"] and
            abs(order.get("size") - new_order["size"]) < 0.0001 and
            abs(order.get("price") - new_order["price"]) < 1.0):  # 价格差异<1 美元
            return True
    
    return False
```

---

### 问题 2: 订单取消后状态未清理

**当前行为**:
- 订单被取消后，`pending_orders` 或 `active_orders` 仍然保留
- 导致后续检查认为订单仍然存在

**修复建议**:
```python
# 在订单取消后立即清理
def cancel_orders(self, symbol, order_ids):
    for order_id in order_ids:
        result = self.binance_client.cancel_order(symbol, order_id)
        if result.get("success"):
            # 清理 pending_orders
            if order_id in self.pending_orders:
                del self.pending_orders[order_id]
            
            # 清理 task.active_orders
            for task in self.execution_tracker._tasks.values():
                if order_id in task.active_orders:
                    del task.active_orders[order_id]
```

### 问题 3: 缺少强制下单机制

**当前行为**:
- 如果"重复委托"检查失败，直接跳过
- 没有 fallback 机制
- 导致系统卡死

**修复建议**:
```python
# 添加最大重试次数
MAX_REPLACE_ATTEMPTS = 10

if replace_attempts > MAX_REPLACE_ATTEMPTS:
    logger.warning(f"ORDER_REPLACE_MAX_ATTEMPTS: {symbol} attempts={replace_attempts}")
    # 强制取消所有旧订单，然后重新下单
    self.force_cancel_all_orders(symbol)
    self.force_create_new_orders(symbol, decision)
    replace_attempts = 0
```
