## 核心功能

### 1. 委托数量限制 ✅

**规则**: 每个交易对最多允许 4 个委托订单

**实现位置**: `order_manager.py` 第 27 行
```python
self.max_orders_per_symbol = 4
```

**检查逻辑**:
- 在 `scale_in` 函数中检查现有委托数量
- 如果达到上限，拒绝新委托
- 提供明确的错误信息：`委托数量已达上限：4/4`

**测试结果**:
```
✅ 委托数量：4/4 - 通过
❌ 委托数量：5/4 - 超限，建议取消多余订单
```

---

### 2. 价格间距检查 ✅

**规则**: 10 USDT <= 委托间距 <= 100 USDT

**实现位置**: `order_manager.py` 第 89-148 行

**配置参数**:
```python
self.min_price_spacing = 10.0   # 最小间距 10 USDT
self.max_price_spacing = 100.0  # 最大间距 100 USDT
```

**检查逻辑**:
- 计算所有相邻委托的价格间距
- 检查最小间距 >= 10 USDT（防止委托过于密集）
- 检查最大间距 <= 100 USDT（防止委托过于分散）
- 返回详细的间距分析（最小值、最大值、平均值）

**测试结果**:
```
✅ 间距 50 USDT - 通过 [10.00, 100.00]
❌ 间距 5 USDT  - 失败，建议：需扩大间距到至少 10.00 USDT
❌ 间距 150 USDT - 失败，建议：需缩小间距到最多 100.00 USDT
```

**优势**:
- 防止委托过于密集导致内部竞争
- 防止委托过于分散导致执行效率低
- 确保合理的价格分布

---

### 3. 趋势判断取消委托 ✅

**规则**: 根据市场趋势智能判断是否取消反向委托

**实现位置**: `order_manager.py` 第 204-311 行

**逻辑流程**:
1. 获取当前市场趋势（UPTREND/DOWNTREND/VOLATILE）
2. 获取趋势强度（0-1 之间）
3. 检查每个委托方向与趋势是否一致
4. 如果趋势强度 > 0.6 且委托方向与趋势相反，建议取消

**判断规则**:
| 市场趋势 | 委托方向 | 趋势强度 | 结果 |
|---------|---------|---------|------|
| UPTREND (上涨) | SELL (卖出) | > 0.6 | ❌ 取消 |
| DOWNTREND (下跌) | BUY (买入) | > 0.6 | ❌ 取消 |
| VOLATILE (震荡) | 任意 | 任意 | ✅ 保留 |

**测试结果**:
```
上涨趋势中的卖单：
  当前趋势：UPTREND
  趋势强度：0.80
  建议取消：['o1', 'o2']
  状态：存在 2 个与趋势冲突的委托

震荡市场：
  当前趋势：volatile
  建议取消：[]
  状态：所有委托状态正常
```

**优势**:
- 避免逆势交易
- 提高委托成交概率
- 降低市场风险

## 完整的委托检查流程

`inspect_all_orders()` 函数执行 6 项检查：

1. **数量检查** (quantity_check) - 最多 4 个委托
2. **间距检查** (spacing_check) - 10-100 USDT
3. **方向检查** (direction_check) - 委托方向一致性
4. **距离检查** (distance_check) - 委托与现价距离
5. **过期检查** (expiry_check) - 订单超时
6. **趋势检查** (trend_check) - 趋势一致性（新增）

## 智能建议系统

`_build_recommendations()` 函数根据检查结果生成建议：

### 示例 1: 间距过小
```
检查结果：最小间距 5.00 USDT < 要求 10.00 USDT
建议：委托价格间距过小 (5.00 < 10.00)，需扩大间距到至少 10.00 USDT
```

### 示例 2: 趋势冲突
```
检查结果：上涨趋势中存在 2 个卖单
建议：趋势检查：建议取消 2 个与趋势冲突的委托（当前趋势：UPTREND，强度：0.80）
```

### 示例 3: 多项问题
```
检查结果：数量超限 + 间距过大 + 趋势冲突
建议：
  1. 委托数量超限 (5/4)，先取消多余订单
  2. 委托价格间距过大 (150.00 > 100.00)，需缩小间距到最多 100.00 USDT
  3. 趋势检查：建议取消 2 个与趋势冲突的委托
```
