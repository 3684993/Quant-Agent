## 二、核心模块功能分析

### 2.1 TradeGuard - 交易守卫层 (⭐️ 核心创新)
**功能特点**:
1. **订单频率控制**: 最小订单间隔300秒（5分钟）
2. **趋势确认机制**: 需要3次确认才能反转方向
3. **最小持仓时间**: 强制30分钟最低持仓时间
4. **持仓规模限制**: 最大仓位0.05 BTC
5. **未完成订单检测**: 防止重复下单
6. **本地SL/TP模拟**: 测试网环境下本地止盈止损

**解决的问题**:
- AI过度下单问题
- 方向频繁反转
- 持仓时间不足
- 仓位过大风险

### 2.2 AI决策引擎
**工作流程**:
```
市场数据 → 特征压缩 → LLM生成决策 → TradeGuard验证 → 执行
```

**决策格式**:
```json
{
  "action": "open_long|open_short|add_position|close_position|hold",
  "entry_range": [low, high],
  "size": [0.01, 0.02],
  "stop_loss": price,
  "take_profit": price,
  "expected_hold_minutes": 60,
  "confidence": 0.8
}
```

### 2.3 风控系统
**多层级风控**:
1. **TradeGuard**: 基础规则约束
2. **RiskManager**: 高级风控（最大回撤、最大亏损）
3. **PositionManager**: 持仓状态管理
4. **ProfitOptimizer**: 利润优化

### 2.4 系统监控
**健康检查项**:
- 交易所API连接
- 代理连接状态
- 内存使用情况
- AI服务状态
- 交易性能监控

```python
# 建议实现
class EquityCurveProtection:
    def __init__(self, max_drawdown: float = 0.10):
        self.max_drawdown = max_drawdown
        self.high_water_mark = 0
        self.current_equity = 0
    
    def should_stop_trading(self) -> bool:
        """检查是否达到最大回撤限制"""
        if self.current_equity > self.high_water_mark:
            self.high_water_mark = self.current_equity
        
        drawdown = (self.high_water_mark - self.current_equity) / self.high_water_mark
        return drawdown >= self.max_drawdown
```
