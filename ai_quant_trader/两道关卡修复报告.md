# 两道关卡修复报告

**修复时间**: 2026-03-13 07:50  
**问题**: 重复委托突破了两道关卡（创建检查 + 合理性检查）  
**根本原因**: 重复检查逻辑有漏洞，只检查价格 + 数量都相同

---

## 问题描述

### 实际案例

**时间**: 2026-03-13 07:45:21

**委托列表**:
1. 70,410.00 - 0.005 BTC (07:45:21)
2. 70,410.00 - 0.002 BTC (07:45:16) ❌ **价格相同，数量不同**
3. 70,421.50 - 0.002 BTC (07:43:10)

**问题**:
- ❌ 两个委托价格都是 70,410.00
- ❌ 数量不同（0.005 vs 0.002）
- ❌ 第一道关卡（创建检查）放行
- ❌ 第二道关卡（合理性检查）没有取消

---

## 根本原因分析

### 第一道关卡：创建时的重复检查 ❌

**之前的逻辑**:
```python
def check_duplicate_orders(self, symbol, side, price, size):
    for order in existing_orders:
        # 检查价格差异
        price_diff = abs(order_price - price)
        
        # 检查数量差异比例
        size_diff_ratio = abs(order_size - size) / max(order_size, size)
        
        # 价格差异 <= 5 且 数量差异 <= 10% 才认为是重复
        if price_diff <= 5 and size_diff_ratio <= 0.1:
            return True  # 重复
```

**问题**:
- ❌ 要求**价格和数量都相似**才判定为重复
- ❌ **价格相同但数量不同**会绕过检查
- ❌ 案例：70,410.00 - 0.005 vs 70,410.00 - 0.002
  - 价格差异 = 0 ✅
  - 数量差异 = (0.005-0.002)/0.005 = 60% ❌
  - 结论：**不是重复**，放行！

### 第二道关卡：合理性检查 ❌

**问题**:
- ❌ 合理性检查在 `_find_duplicate_orders()` 中只检查价格完全相同
- ❌ 但实际案例中两个委托价格都是 70,410.00，应该被检测到
- ❌ **为什么没有取消？**

**原因**: 合理性检查器刚创建，可能还没有正确集成到调度器中，或者调用时机不对。

    logger.warning("发现重复委托，跳过执行")

**检查逻辑**:
```python
# _find_duplicate_orders() 方法
def _find_duplicate_orders(self, symbol, orders):
    price_map = {}  # price -> [order_ids]
    
    for order in orders:
        price = float(order.get("price", 0) or 0)
        order_id = order.get("order_id", "unknown")
        
        if price in price_map:
            # 发现重复价格，标记为重复
            duplicate_ids.append(order_id)
            logger.warning(f"发现重复价格委托：{order_id} @ {price:.2f}")
        else:
            price_map[price] = [order_id]
    
    return duplicate_ids
```

**效果**:
- ✅ 每个周期自动检查
- ✅ 发现重复价格委托立即取消
- ✅ 70,410.00 出现两次 → **取消后一个！**

## 注意事项

### ⚠️ 1. check_price_only 参数

**使用场景**:
- ✅ 创建新委托时：`check_price_only=True`（严格检查）
- ✅ 合理性检查：使用默认逻辑（检查价格相同）

### ⚠️ 2. 价格容差

**设置**:
```python
if abs(float(order_price) - float(price)) < 0.5:  # 0.5 USDT
    return True
```

**原因**:
- 允许微小的价格差异（如四舍五入）
- 0.5 USDT 对于 BTC 来说非常小

### ⚠️ 3. 合理性检查频率

**频率**: 每个交易周期（约 5-10 秒）

**时机**: 在市场数据分析之前

**优先级**: 最高
